# KupuLampa

Плагин для [Lampa](https://github.com/yumata/lampa) — «Гарри Поттер 4K».

- Пункт меню **«Гарри Поттер 4K»** — все 8 фильмов серии по порядку выхода (данные TMDB).
- Плеер Lampa автоматически выбирает **2160p (4K)**, если источник его отдаёт, иначе — лучшее доступное качество.
- Настройки → **KupuLampa** → «Всегда 4K (2160p)» — можно выключить.

## Установка

Настройки → Расширения → Добавить плагин → введите ссылку и перезапустите Lampa:

```
https://kirillka645.github.io/k.js
```

> Плагин не содержит и не добавляет источники видео: 4K будет там, где его отдают ваши подключённые источники.
