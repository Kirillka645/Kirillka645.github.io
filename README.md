# KupuLampa

Плагин для [Lampa](https://github.com/yumata/lampa) — «Гарри Поттер 4K».

- Пункт меню «Гарри Поттер 4K» содержит восемь фильмов серии по порядку выхода (данные TMDB).
- В списке источников на карточках этих фильмов есть **KupuLampa**. Он обращается напрямую к API Alloha и открывает её веб-плеер, без KupuLand и BwaRC.
- Используется публичный токен из клиента [anime-dl-core](https://pypi.org/project/anime-dl-core/), его доступность может измениться.
- Настройка «Всегда 4K (2160p)» задаёт предпочтение в Lampa, но не гарантирует 4K: качество зависит от источника и плеера. Доступность Alloha и поддержка телевизора тоже могут отличаться.

## Установка

Настройки → Расширения → Добавить плагин → введите ссылку и перезапустите Lampa:

```
https://kirillka645.github.io/k.js
```
